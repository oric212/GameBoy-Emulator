# Game Boy Emulator

This project is a Game Boy emulator written in C++ for Windows-based x64 systems.

## Overview

This project is dedicated to learning low-level programming, CPU architecture and instruction execution, memory systems, and desktop application development.

All emulator implementation code in this repository is written manually. AI usage is limited to learning new concepts, finding relevant resources, reviewing code that I have already written, and refining documents that I wrote myself.

## Goals

Project goals are documented in [docs/00-project-goals.md](docs/00-project-goals.md).

## Current Status

Initial repository setup and documentation are complete.

Emulator implementation has not started yet.

## Documentation

The `docs/` folder contains documentation of the learning process, project goals, debugging notes, and technical topics studied throughout development.

## AI Usage

AI usage is limited because this project is primarily intended as a learning experience.

### Allowed Uses

1. Refining documents that I wrote manually.
2. Learning new concepts and C++ features.
3. Finding documentation and learning resources.
4. Reviewing code that I have already written in order to explain bugs, incorrect behavior, or relevant concepts.

### Restricted Uses

1. Generating emulator implementation code.
2. Writing technical documentation from scratch.
3. Suggesting concrete replacement code or code changes when reviewing bugs.
4. Adding technical information to the project that I do not understand or cannot explain myself.

When AI is used for debugging, it may explain what is wrong, why the behavior occurs, and which concepts or areas of the code I should investigate. The actual solution and code changes must be designed and implemented manually by me.

Any AI-assisted changes to documentation must be reviewed and understood before they are added to the repository.
