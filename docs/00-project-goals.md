# Project Goals

## Introduction

I have always had an interest in emulators as a concept, growing up I have tried various emulators.
Emulators seemed to me like a magical program that imitates the original system that it was based on,
while improving the overall experience with higher resolution and framerate, with the added benefit of hacks
such as fast forward, widescreen support, save-states and more.

As a CS student, I thought that, given my current knowledge, I could build an emulator myself.
Handheld systems were always a favorite of mine, since the developers were always required to adjust
to the hardware constraints, in contrast of console game devalopment.

This project started as a combination of my passion for video games and my desire to learn low-level programming.
AI usage will be limited to learning new concepts only, this project will not include any AI-generated code.


## Milestones

- [ ] Learn the basic architecture of the Game Boy
- [ ] Load a Game Boy ROM and inspect its cartridge data
- [ ] Represent the CPU registers and internal state
- [ ] Implement the Game Boy memory map and memory bus
- [ ] Implement the CPU fetch-decode-execute cycle
- [ ] Implement the CPU instruction set
- [ ] Test and validate CPU behavior with diagnostic ROMs
- [ ] Implement timers and interrupts
- [ ] Implement the PPU and render graphics
- [ ] Implement joypad input
- [ ] Get a simple commercial game running
- [ ] Add support for cartridge memory banking
- [ ] Implement the Game Boy audio system
- [ ] Add debugging tools and improve game compatibility
